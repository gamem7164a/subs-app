APK 만드는 법
1. github.com 에서 새 저장소(Repository)를 만든다. (Public이든 Private이든 상관없음)
2. 이 폴더 안의 모든 파일과 폴더(.github 포함)를 저장소에 올린다.
   (웹에서 Add file > Upload files, 숨김 폴더 .github 도 꼭 올려야 함)
3. 저장소의 Actions 탭에서 'Build APK'가 끝나길 기다린다(약 5~10분).
4. 완료된 실행을 눌러 맨 아래 Artifacts의 subs-app-apk 를 받는다(zip, 안에 app-debug.apk).
5. 폰으로 apk를 옮겨 설치한다. ('출처를 알 수 없는 앱 설치' 허용 필요)
